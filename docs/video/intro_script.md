# Video Opening - Spoken Draft

Hi everyone, welcome to this project. In this series, we're going to build an end-to-end Investment Research AI system on Databricks. And I don't want this to be another demo where we upload a PDF, ask a question, and call it an AI agent. We're going to start with the business problem, build the data foundation, add retrieval and business semantics, create specialized agents, connect them through multi-agent orchestration, and then take the solution all the way into evaluation, security, deployment, memory, human feedback, and production monitoring.

For the project I'm using a fictional investment company called Investment AI, and all of the companies, research documents, portfolio positions, and financial numbers you'll see are synthetic and created only for this demonstration. The main question we want our system to answer is: which companies lowered their outlook this quarter, why did they lower it, and how much do we currently own of those companies? It sounds like one simple question, but the answer is spread across two very different worlds. The guidance and management commentary live in unstructured research documents, while our exposure lives in structured portfolio data. So the real challenge is getting the platform to understand both sides, use the right capability for each part of the problem, and return one trusted answer.

Before we start writing notebooks, I want to show you how the repository is organized. I'm deliberately not going to keep the entire application inside a notebook folder. We'll use notebooks for learning and experimentation, but once a component becomes stable we'll move the reusable implementation into `src`, add tests, evaluation data, configuration, architecture decisions, application code, and eventually deployment resources. The repository already contains the synthetic source material so we can focus on building the platform rather than manually creating files during every episode.

Once this repository is connected to Databricks, we'll start with Notebook 00, validate the environment, and then build the POC one layer at a time from the ground up.
